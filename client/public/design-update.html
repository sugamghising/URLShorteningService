The Design System

No gradients · Flat cards · Playfair + Inter
01

Palette

Navy #162540, warm paper #faf9f7, amber accent #c9a227, slate text #475569. No gradient washes — color is used structurally.

02

Type

Playfair Display for headlines (character, contrast), Inter for body (clarity, scale). No all-caps labels, no decorative italic words.

03

Layout

Left-aligned content at 65ch line length. Cards use flat borders and subtle fill — not rounded shadow cards. Hierarchy by size, not by decoration.

Technical Highlights

The backend architecture that supports the redesigned frontend.

Secret-Key Authentication

Per-URL 32-character unguessable keys (~157 bits entropy) generated with nanoid. No user login required — possession of the key grants update/delete access. Routed through secretAuth.middleware.ts.

Authentication

32 chars

X-Secret-Key header · Middleware on PUT / DELETE

Rate Limiting & Security

Multi-layer express-rate-limit: global (200/15min), create (100/15min), get (60/min), modify (30/15min). Custom error classes in utils/errors.ts with consistent {status, message} responses.

Rate Limits

4 layers

Standard headers · 429 responses

Database & Serverless

Mongoose with cached connection for serverless cold-start reuse. Dynamic import("nanoid") handles ESM/CJS interop (nanoid v5 is ESM-only). Zod validates env vars at startup.
